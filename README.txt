ALEXIE'S CROSSWORD ACADEMY — GITHUB PAGES

1. Sign in to https://github.com (or create a free account).
2. Create a NEW PUBLIC repository named alexie-crossword.
3. In the repository, choose Add file > Upload files.
4. Upload the file index.html from this folder (NOT the ZIP file).
5. Commit changes.
6. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. After deployment, open https://YOUR-USERNAME.github.io/alexie-crossword/
   (replace YOUR-USERNAME with your GitHub username).
9. On iPhone/iPad: open that link in Safari > Share > Add to Home Screen.

For future updates: replace index.html in the same repository, then commit changes.
Custom words added inside the game are stored in that browser only. Use Word bank > Export to back them up. They do NOT automatically sync across devices.

Note: Public GitHub Pages repositories are accessible to anyone with the link. Do not add personal information to the word bank or website.
